🚀 Getting Started
Prerequisites
Java Development Kit (JDK 8 or higher)
Any Java-supported IDE (IntelliJ IDEA, Eclipse, VS Code)
How to Run
Clone the repository

 git clone https://github.com/sadik281/oop-java-practice.git
cd oop-java-practice


Open in your IDE


Import the project into your preferred Java IDE
Wait for the IDE to index the files
Compile and Run

 javac YourFileName.java
java YourFileName



💡 Learning Approach
This repository follows a concept-first methodology:
Understand – Grasp the theoretical foundation
Implement – Write code to apply the concept
Practice – Solve related problems
Refine – Improve code quality and efficiency
Note: The focus is on understanding OOP concepts rather than advanced optimization. Code clarity and learning value take priority.
